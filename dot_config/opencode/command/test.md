# Testing Pipeline

This command runs the complete testing pipeline for the project.

## Usage

To run the complete testing pipeline, just type:

1. Run nr lint
2. Run nr format
3. Run nr test
4. Report any failures
5. Fix any failures
6. Repeat until all tests pass
7. Report success

## What This Command Does

1. Runs `nr lint` to check for type errors
2. Runs `nr format` to check for linting errors
3. Runs `nr test` to run the tests
4. Reports any failures
